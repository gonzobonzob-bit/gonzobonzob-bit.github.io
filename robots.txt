# Crawler policy for the whole of gonzobonzob-bit.github.io
#
# WHY THIS FILE IS HERE: crawlers only read robots.txt from the ROOT of a host.
# A robots.txt inside a project-site repo (e.g. /pv-tools/robots.txt) is never
# fetched and has no effect. This file, served from
# https://gonzobonzob-bit.github.io/robots.txt, is the only one that is actually
# read - and because every GitHub Pages project site shares this hostname, it
# governs all of them at once:
#
#   /pv-tools/**        PV field tools (PW3 String Analyzer, Lynx, Magpie)
#   /pv-ct-review/**    Lynx (standalone, legacy)
#   /magpie-notes/**    Magpie (standalone, legacy)
#   /my-games/**
#   /solar-reference/**
#
# Nothing on this host is intended for search results.
#
# NOT ACCESS CONTROL: robots.txt is a request, honored voluntarily. It keeps
# well-behaved crawlers out; it does not stop anyone who has a URL from opening
# it, and it does not stop crawlers that ignore the standard. The load-bearing
# per-page protection remains the <meta name="robots" content="noindex"> tag in
# each page, which works regardless of path and cannot be skipped by a crawler
# that fetched the page. Belt and braces: keep both.

User-agent: *
Disallow: /
